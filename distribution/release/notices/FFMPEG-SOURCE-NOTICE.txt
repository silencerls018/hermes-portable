Separate source material accompanies the runtime release, including the fixed
FFmpeg tree, dependency source commits and recipe-required submodules, exact
SVN revisions, rav1e Cargo.lock crate archives, and the identified crosstool-NG
recipes, GCC sources, and MinGW toolchain sources. The source attachment's
manifest and SHA256SUMS describe what was collected and any unresolved gaps.
Source materials must remain available alongside the binary release:
  https://github.com/silencerls018/hermes-portable/releases

Source collection is not a claim of bit-for-bit binary reproducibility. The
upstream recipe references a floating base container and performs cargo update
cc for a rav1e build-only dependency. The original resulting base-image digest
and updated cc version are not declared by that recipe. These limitations are
recorded in the source inventories; no replacement versions are represented as
the original build's versions. The recorded binary buildconf is also supplied.

The source archive is an intentionally broader collection than win64-gpl needs;
some included recipe sources are disabled in the actual binary buildconf.
