DOPI portable Hermes runtime: third-party material

This distribution adapts the official Nous Research Hermes Agent. The Hermes
source and its MIT license remain in the hermes-agent directory. DOPI's private
application source is not part of this independent runtime distribution.

The runtime includes these independently maintained components. The exact
upstream download URLs and SHA256 values are pinned by pm/lock.json. Preserve
their existing license, copyright, notice, and package metadata files when
building or updating the runtime.

Source material collection

Git/component source archives are prepared as a separate release attachment,
not placed inside the executable runtime or committed as large Git objects.
The source-materials.json and source-inspection.json accompanying that attachment
record exact package-version mappings, official source URLs, local SHA256 values,
upstream digest verification where available, embedded PKGBUILD/.SRCINFO metadata,
and unresolved gaps. GCM 2.7.3 has a separate official tagged source archive;
its MIT license remains at mingw64/doc/git-credential-manager/LICENSE.

These inventories are evidence of collected material. They do not assert that
all binaries have been reproducibly rebuilt or that every transitive source
requirement has been independently established. Before public release, retain
the license texts and publish the completed source attachment beside the binary
with the same access conditions; review any gaps reported by the inventories.

FFmpeg requires a separate version-specific source and license inventory before
the final runtime is distributed. Consult the final release inventory for the
exact FFmpeg build; this notice does not classify it as an optional dependency.
